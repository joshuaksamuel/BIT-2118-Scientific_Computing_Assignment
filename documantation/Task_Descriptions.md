TASK DESCRIPTIONS

This document provides a summary of the nineteen practical tasks completed for BIT 2118 – Scientific Computing.

Task

Topic

Description

A

NumPy Arrays

Demonstrates numerical arrays and operations using NumPy.

B

Vectorization

Demonstrates performing computational operations efficiently on numerical data.

C

Floating-Point Errors

Examines floating-point representation and numerical precision issues.

D

Matrix Operations

Demonstrates matrix representation and mathematical transformations.

E

Linear Equations

Solves a system of linear equations using numerical computation.

F

LU Decomposition

Demonstrates the use of LU decomposition in solving linear systems.

G

Iterative Methods

Applies iterative numerical techniques to computational problems.

H

Eigenvalues and Eigenvectors

Demonstrates eigenvalue and eigenvector calculations.

I

Root Finding

Applies the bisection and fixed-point methods to find roots of equations.

J

Numerical Root Finding

Demonstrates Newton-Raphson and secant methods.

K

Nonlinear Equations

Applies numerical methods to solve nonlinear equations.

L

Interpolation

Estimates unknown values between known data points using linear and cubic interpolation.

M

Curve Fitting

Demonstrates fitting a mathematical curve to a given dataset.

N

Numerical Differentiation

Estimates derivatives numerically using discrete data.

O

Numerical Integration

Approximates definite integrals using numerical techniques.

P

Euler's Method

Applies Euler's numerical method to solve an ordinary differential equation.

Q

SciPy ODE Solver

Uses SciPy's solve_ivp function to solve an ordinary differential equation.

R

Optimization

Demonstrates numerical optimization techniques subject to given conditions.

S

Monte Carlo Simulation

Uses random sampling and simulation to estimate computational results.

Summary

The nineteen tasks cover a range of scientific computing concepts, from basic numerical operations to more advanced numerical methods, differential equations, optimization and simulation.

Each task is implemented in its own Jupyter Notebook. The corresponding screenshots are available in the screenshots directory.
